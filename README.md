# 알트모아 (Altmoa)

알트코인 관심도 순위와 커뮤니티의 첫 프로토타입입니다.

## 실행

`dist/index.html`을 브라우저로 열거나 프로젝트 루트에서 `python3 -m http.server 8000`을 실행한 뒤 `/dist/`로 접속합니다.

## Vercel

- Framework Preset: Other
- Build Command: 비움
- Install Command: 비움
- Output Directory: dist

`vercel.json`에 위 설정이 포함되어 있습니다.

## 현재 지원

지역·기간 필터, 관심도 정렬, 검색, 코인 상세, 브라우저 내 관심 코인 및 게시글 저장.

시세, 언급량, 관심도 추이 및 기본 게시글은 예시 데이터입니다. 로그인, 외부 데이터 수집, 서버 게시판 저장, 댓글은 아직 연결되지 않았습니다.
