# Image sources

- `dist/assets/altmoa-logo.png`: original transparent PNG supplied by the site owner, used unchanged.
- Coin icons: `https://static.upbit.com/logos/{SYMBOL}.png`, using the same ticker symbols as the Upbit market feed. Verified examples: BTC and XRP. Icons are loaded directly from Upbit; missing icons use a letter fallback. Logos remain the property of their respective owners.
